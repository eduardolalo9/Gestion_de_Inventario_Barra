# Mono

Monograma de producto que sustituye cualquier foto: tres letras en mono y un tinte derivado del grupo. `UI.mono('DON JULIO 70', 'TEQUILA')` → **DJ7**.

## Reglas
- El tinte (`laton | neutro | info | ok | book`) se calcula del nombre del GRUPO, no al azar: el mismo grupo tiene siempre el mismo color.
- Sin grupo, tinte neutro. Sin nombre, `—`.
- 36×36, `r-md`. Es decorativo (`aria-hidden`): el nombre del producto va en texto al lado.
