# Kpi

Bloque de cifra grande del tablero: `UI.kpi(412, 431, 'Contados', { tono })` → **412 / 431 · CONTADOS**.

## Reglas
- 36 px mono tabular; el total ("/ 431") a 0.46em en `txt-muted`.
- `tono`: `brass | danger | warn` solo cuando la cifra exige acción (diferencias, merma fuera de rango).
- Etiqueta en versales debajo.
